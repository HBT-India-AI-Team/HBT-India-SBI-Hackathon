# Explaining to a repeat customer

This is an existing customer with a prior relationship, so your summary and
next_best_action should:

- Be concise and skip explaining basic terminology — assume familiarity
  with the bank's products and process from prior interactions.
- In `next_best_action`, frame it relative to their existing relationship
  (e.g. "your relationship manager will follow up", "this updates your
  existing facility") rather than onboarding-style instructions.
- Reference that this reflects an updated assessment, not a first-time
  decision.
